# Diploma_NevoScan

Данная дипломная работа посвящена разработке и экспериментальному исследованию
интеллектуальной системы NevoScan для автоматизированного анализа дерматоскопических
изображений. Основной целью работы является обеспечение интерпретируемости онкологического
диагноза путем выявления и визуализации семи ключевых клинических признаков рака по
системе "Argenziano 7-point checklist".
